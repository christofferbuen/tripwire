Keeping a static site boring

11 March 2026

Every few years I rebuild this, and every time the answer is fewer moving parts. Plain files, one stylesheet, no build step to rot.

The last version had a generator, a theme, a plugin for footnotes and a lockfile with four hundred entries in it. It worked beautifully for about eight months. Then the generator went to a new major version, the theme did not follow, and publishing a paragraph became an afternoon.

The cost of a tool is not what it takes to set up. It is what it takes to still be running in three years.

So: files. I write the HTML. The nav is copied into each page by hand, which sounds worse than it is, because there are five pages and they change once a year.
